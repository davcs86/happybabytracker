Route /kids/[kid]/access (guardian only)
Who can see the child. Left: the people with access, each with “Make caregiver / Make guardian” and “Remove access”. Right: “Add a person”. A caregiver gets the same “Not found” as for an unknown child.

Rules shown
The only active guardian cannot be changed or removed: the buttons are aria-disabled with the sentence under them, and a server refusal shows “A child needs at least one active guardian.”

No JS
Role change: a POST per person. Remove access: a confirm page /kids/[kid]/access/[person]/remove that lists the consequences and has “Remove {name}” and Cancel. Add a person: a POST to this route.
