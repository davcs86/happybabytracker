One page, two links
Invite and reset share the form; only the heading, lead and the success line differ. The username is shown read-only so a password manager saves the right account.

Link states
A used, expired or unknown link all read the same: “This link is no longer valid”, with how long that kind of link lasts. The form is not shown.

Validation
Under 12 characters is refused on the field. A mismatch is checked in the browser and says so on the confirm field. A rate limit shows an alert above the form.

After saving
Invite signs the parent in and lands on the welcome state (no child yet). Reset signs the other devices out.

No-JS baseline
A form POST to /invite/[token] or /reset/[token]; the response is this page with the message.
