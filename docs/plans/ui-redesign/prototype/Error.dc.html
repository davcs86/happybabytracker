Two pages, outside the shell
Both render without the tabs, bell or switcher, so a failing API can’t break them.

404
An unknown child, a child without access, a path that doesn’t exist, and a parent opening an admin address all show this same page. Nothing says which case it was, so it doesn’t reveal that a child exists.

503
The API is down, unavailable or slow. The session is kept, so Try again reloads the same address.

Where it applies
Every page’s “Couldn’t save” and “No connection” toasts stay as they are; this is for a whole page that can’t load.
